# Review image-to-code transfer

Inspect generated images before implementation and the actual coded screen
before delivery. Use fresh-context critics for consequential visual choices.
Provide readable source and candidate images, the intended action, audience and
constraints. Do not supply the builder's preferred verdict.

Ask for localized evidence: typography roles and letterforms, density, component
geometry, hierarchy, alignment, state coherence and usefulness. Separate visual
estimates from measured CSS values. Generated text does not prove font identity.

Keep atmosphere and composition separate from exact utility geometry. A rendered
component study can anchor fonts and control metrics without supplying a layout.
Attach it for that job; do not accidentally transfer its comparison-board panels
into the product.

Retain useful differences and unresolved taste choices. Reconcile disagreement
with a concrete comparison rather than averaging incompatible designs. Carry
findings into the next generation call or implementation change and inspect the
result. Reviews and passing pixel checks do not establish actual behavior.
