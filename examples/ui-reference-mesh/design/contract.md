# Authored fixture visual contract

Use warm paper surfaces, compact utility controls and selective display headings.
Geist supplies utility typography; Fraunces supplies display typography. Official
Hugeicons supplies the icons. Font and icon provenance and full licenses are
stored alongside the assets. These are chosen assets, not inferred identities
from generated lettering.

Keep collection navigation, reference selection and editing legible. Preserve
real record counts, membership, filtering and draft state. Do not copy invented
content or unsupported controls from a design concept.

Desktop control geometry and touch targets need separate checks. Render real
components at the intended viewport before using them as image-model anchors.
A screenshot's raster dimensions do not establish CSS scale or device pixel ratio.

For a new visual direction, attach inspected source images with explicit jobs.
Let the image model explore composition; keep behavior and usable font/control
anchors fixed. Compare multiple interpretations when that resolves uncertainty.
Fresh-context critique should inspect source and candidate pixels without a
favored answer. A rejected image is not an implementation baseline.

The fixture is an authored test surface. It does not establish user approval,
exact reference fidelity or a general taste evaluation. Private reference images
and generation history remain outside the public repository.
