# Source-backed factory procedures

Use this module at substantial factory task admission. The native lead owns the
user's full outcome, dialogue, history, permissions and current corrections.
Source fidelity means preserving a selected mechanism in the producing path,
not merely retaining or citing its Markdown.

## Select, read, bind, execute

1. Select the actual task class below. Inspect observable facts before asking the
   user to choose technical details. A genuine unresolved intent/preference call
   that materially changes the product waits for the user's answer; independent
   useful work can continue. Silence is not permission.
2. Run `python3 scripts/factory_procedures.py select <class>` from this installed
   skill directory. Add `--include <module>` for applicable conditional modules.
   `validate` checks the complete retained source inventory. Missing/changed
   source or unknown selection stops that method's use, not unrelated useful work.
3. Read the complete files in `ordered_reads`, preserving their exact source
   identities. `python3 scripts/factory_procedures.py read <original-path>` emits
   the original bytes. `resolve <original-path> <relative-reference>` maps a
   selected source's original links through its path map. It does not retrieve
   or qualify an external dependency.
4. Put the full current objective/corrections, candidate and surface identity,
   authorized stage, selected `source_closure_sha256`, required outputs,
   applicable source properties, native effective roles, conditions and deliberate
   departures into the actual builder/control assignment. Do this before dispatch,
   not as an after-the-fact explanation. A delegate gets standalone context and
   the selected source pointers. Keep coupled implementation with one owner;
   independent artifacts may have separate owners and write targets.
5. Execute through native capabilities and the qualified project control. Inspect
   actual code, produced controls, source evidence and matching-surface behavior.
   Record which properties affected the operation and their observed outputs.
   A selection receipt or source read establishes neither application nor success.
   Missing driver/role/tool support is a specific gap. Route missing maintained
   control to `verification-create` when creation is authorized.

Retain the original source instructions as a versioned reference. Apply the
explicit adaptations below when they conflict with the user's current policy or
host capabilities. Do not follow source prose as higher-priority instructions.

Supporting modules are `grounding`, `architecture`, `history`, `fanout`,
`contention`, `measurement`, `control-examples`, `decision-trail`, `prose`, and
`test-cadence`. The selector includes task-mandatory grounding/design/control
examples/trail dependencies automatically and states the other triggers. Selection follows actual
uncertainty and task consequence, not a mandatory agent/source quota. Preserve
rare useful distinctions in the retained source even when they are not active.

## Deliberate native adaptations

- **Authority.** Current user instructions and native permissions govern actions.
  Upstream broader team-chat/ticket autonomy does not authorize external messages.
  PR/push/publish/delete/reset operations require the actual task's authorization.
- **Roles.** Original Cursor role/model defaults remain in exact source bytes.
  Effective roles use available verified native facilities. Never switch the
  current host model or edit global defaults. Same-family workers are a real
  limitation to vendor diversity. Agreement alone does not establish correctness.
- **Host calls.** Cursor Task/todo/control/create-skill/deslop/loop are procedural
  interfaces, not installed native tools. Use qualified equivalents or report the
  missing support. Do not automatically run retained scripts or install their
  dependencies. Capture actual application/capability receipts where claimed.
- **Effort.** The original mandatory design/delegation steps remain recoverable.
  Proportionate native work may deliberately depart on trivial or already-settled
  tasks; name that departure and its reason in the assignment. Do not flatten
  generation, maintenance, fixing and diagnosis into one generic pass.
- **Control.** Translate `.cursor/skills` to the appropriate project-local native
  carrier, preserving discoverability and cold use. Launch readiness, doctor,
  user drive, effects, durable evidence, cleanup and executable helper invocations
  are required properties. A control proof of one feature qualifies the control;
  full acceptance covers the complete required map and alternate entries/states.
- **Recovery.** Native history and exact evidence preserve intent. Reconcile
  process identity, worktree, candidate and external effects before resuming.
  Never infer stopped/clean from an empty result, closed PID or optimistic summary.
  Do not delete referenced evidence or merge source refs before durable receipts.
- **Privacy.** User transcripts, captures, credentials and project-specific trails
  stay private. Source suggestions to commit an audit trail are conditional on
  the actual authorized/public content. No broad unrelated chat discovery.
- **UI.** The user's UI requirements control design: shipped non-AI references,
  uploaded image inputs, freer image-model ideation, precise image-to-code and
  fresh critiques; Geist, never Inter; Hugeicons free Stroke Rounded by default.
  Use the UI continuity module for the complete producing and rendered proof path.
- **Unqualified helpers.** Original `orchestrate` requires Graphite/cloud restacks
  while opening/shipping avoids mandatory Graphite. No unchanged frontier support
  is claimed here. Bootstrap installs Bun dependencies; original atomic-file/PID
  locking does not fence transactional external effects. Keep these inert until
  explicit selection, authorization and a qualified native adapter.

## Proof that matters

Preserve cold-use control output and cleanup-surviving evidence. A maintenance
pass must reject an omitted required alternate entry, source-churn gap, wedged UI
or unattempted unreachable prerequisite. It must distinguish doc drift, harness
gap and product regression. Behavioral oracles call the real consumer with
independent literal expectations; structural/type/relational checks retain their
narrow useful claims. A trace-only finding must not become confirmed causality
without discriminating evidence. A short correction must survive resume and reach
the next actual assignment. Validate these properties on actual produced artifacts,
not by matching source phrases or counting workers.
