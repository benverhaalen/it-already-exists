# Investigate fidelity bottlenecks

Use this module when reconstruction or repair depends on uncertain behavior.
Choose relevant mechanisms; do not require every technique for every artifact.
The objective is the same accepted experience with less whole-work cost. More
features, internal tests or cache hits do not establish that outcome.

## Research recursively from failures

Start with a complete normal-entry journey, reference version, access policy and
observable success. Describe each bottleneck independently of its domain labels.
For each seed, record parent evidence, competing explanations, primary-source
inspection, useful invariant, adaptation, test, cost and remaining uncertainty.
Inspect actual producing code and tests, not only README claims.

Use an output's unresolved mechanism as a child seed: what assumption makes the
remedy work, what it still misses, and what observation would distinguish an
alternative? Investigate children separately so small differences survive. Link
them through the existing journal and optional `research_frontier`; avoid copying
source archives into every worker. Inspect a neglected or structurally distant
mechanism when it could change the decision. Bound each branch by a decision and
probe, preserve deferred ideas, and stop convergent search. A requested number of
rounds is a research bound, not evidence of exhaustive coverage.

Compose only after identifying dependencies and conflicts. Compare original,
adapted and combined mechanisms on fixed accepted properties. Keep specialists
conditional rather than forcing incompatible policies into one universal route.
For strict clean-room work, this research is analyst-side; implementation access
requires the independently reviewed export and verified isolation described in
[clean-room boundaries](clean-room.md).

## Seven recurring mechanisms

| Failure mechanism | Producing operation | Discriminating evidence and limits |
| --- | --- | --- |
| An implementation and its tests share a wrong assumption | State competing models; choose inputs where their predictions differ. Record oracle machine/version, modes, input identity, topology and observer. Independently author holdouts and seed known defects into the evaluator. For record joins, trace the original caller's identifier role through full scoped references; use distinct parent/child IDs and same-tail IDs in different collections | Recompute after edits without reference caches; compare to an independent oracle. Metamorphic agreement needs absolute anchors: constant outputs can pass identity relations. A nearby platform or self-authored model has narrower authority than the target |
| Matching results conceal different histories, callbacks or buffer lifetimes | Capture ownership, read/write, entry/return, event delivery and durable completion as distinct events. Keep observed edges separate from inferred requirements. Verify reset uncached before caching or deterministic learning | Vary disputed dependent orderings; test cancellation, destruction, no-next-action and restart. Record bounds, explored cases and exhaustion versus timeout. Replay preserves one witnessed failure; a bounded model is not the original system |
| Reuse is fast only while every mutation is observable | Inventory owners, aliases, external writers and backing generations. Separate semantic stages; track actual dependencies and bypass reuse for untracked state, incomplete work or stale completion | Compare cached/uncached outputs after external edits, same-path replacement, remap, eviction and cancellation. Measure key validation, locks, copies, readback and total live memory. Tiles require finite dependency footprints; global/temporal operations can need full recomputation |
| Feature counts reward disconnected breadth | Build observable obligations and predecessor closures from whole journeys. Protect required gates, known counterexamples and consequential tail cases. Recompute marginal whole cost; retain low-ranked ideas with revisit triggers | Generate constrained interactions, then stateful repeated histories. Independently audit achieved coverage. Code/tuple/export counts have explicit denominators; none imply reference agreement. Keep semantic witnesses when reducing an execution corpus |
| A better primitive changes the reference's chosen semantics | Declare each operation's relation: exact bits, target approximation, mathematical rounding, bounded error, semantic invariant or visual tolerance. Record domains, modes, substitute and uncovered forms | Independent high-precision checks for mathematical contracts; tiny boundary/color fixtures for representations. Capture intermediate and final outputs separately. Perceptual similarity can conceal export or later-edit errors; a baseline variability test cannot certify its own correctness |
| Opening a file or loading a plugin is mistaken for editable compatibility | Qualify parse, preserve, edit, render, export, original-host reopen and subsequent edit separately. Preserve unfamiliar extensions with schema identity, ownership and edit-dependent invalidation. Negotiate actual host/ABI versions and lifecycle | Compare payload, semantics and rendering independently. Test missing media/fonts/plugins and version migrations. Unknown bytes are not understood behavior; native plugin support is not provided by a new portable plugin ABI. Parser, guest and blocked host-call budgets need separate controls |
| Automation succeeds while the real visible journey fails | Record discovery, actuation and observation separately. Keep the normal launch flags, default profile and recovery lane; promote only consequential paths to external drivers | Test hit regions, focus, modal flows, display density, stale presentation and acknowledged device loss. A command/export can succeed while the displayed image is stale. Accessibility queries may drive pointer input; inspect actual execution rather than judging the tool name |

## Compose a practical route

Start with an oracle and a contract that can reject a wrong implementation.
Select the earliest unresolved dependency blocking the accepted journey. Use cheap
primitive/component tests for diagnosis, preserving independent anchor cases.
Before changing an adapter, resolve the selected target's actual source files,
registration entry point and embedded artifact. A compiled plugin or a fix in a
similarly named source file does not establish runtime registration. Confirm the
new build's receipt, then repeat the failed journey: removing an exception alone
does not establish that it caused the visible failure.
Add controlled histories or constrained interactions for the actual risk; reduce
failures while preserving their semantic witness. Carry the resulting reviewed
contract into implementation, then verify normal entry through durable delivery
and cold reopen. Only optimize repeated work after checking mutation, reset,
backend and observation conditions. Recheck the complete combination.

Supporting OSS mechanisms, each with a specific job:

- [AALpy conformance](https://github.com/DES-Lab/AALpy/blob/335c50a1b4b5a830d788f86b7c30a8cb6c73ecc0/aalpy/oracles/WpMethodEqOracle.py): distinguishing histories. Audit state bounds and generated case count; invalid bounds can leave an empty suite. MIT.
- [Loom execution](https://github.com/tokio-rs/loom/blob/948c8cc78b178ede6eeff3afc7d97f2f4ea08559/src/rt/execution.rs): dependent-access backtracking. Requires an instrumented model and declared search bounds. MIT.
- [Salsa dependency verification](https://github.com/salsa-rs/salsa/tree/30b614d826d697c47bc0f21591fab218f2004032): tracked reads and semantic backdating. Untracked branch state defeats its premise. MIT OR Apache-2.0.
- [libvips region evaluation](https://github.com/libvips/libvips/blob/6b5dcce25fbf2642647bc180eb19c35de864eb4a/libvips/iofuncs/region.c): demand-driven processing. Choose access and retention policy for the workload; total external memory needs separate accounting. LGPL-2.1.
- [PICT](https://github.com/microsoft/pict/blob/ab76c2548f551fcb46314e58653a1bd1172f3a72/doc/pict.md) and [Hypothesis stateful rules](https://github.com/HypothesisWorks/hypothesis/blob/ca2a4c6e3c6b979d9fbb5ef9db614885a736d2aa/hypothesis/src/hypothesis/stateful.py): legal combinations followed by repeated action sequences. Neither supplies unknown reference behavior. MIT; MPL-2.0 respectively, with applicable file exceptions.
- [LLVM libc MPFR matcher](https://github.com/llvm/llvm-project/blob/30a48d7dfb3fc6a37f89db9557716d8b7a8f0beb/libc/utils/MPFRWrapper/MPFRUtils.h): independent mathematical relations and rounding checks, not proprietary approximation recovery. Apache-2.0 WITH LLVM-exception.
- [OpenTimelineIO unknown schemas](https://github.com/AcademySoftwareFoundation/OpenTimelineIO/blob/dcf9ac17698db2e13c094abf54a636fec1cb8e14/tests/test_unknown_schema.py): unfamiliar schema retention alongside typed nested values. Preservation still needs an edit-dependency policy. Apache-2.0.
- [OpenFX host contracts](https://github.com/AcademySoftwareFoundation/openfx/blob/e40728885390ec16276d11e00025de9b4282060c/include/ofxCore.h): versioned suite negotiation, not compatibility with unrelated proprietary plugin ABIs. BSD-3-Clause.

These are inspected references, not bundled dependencies or executed adapters.
No upstream code is copied here. Recheck relevant licenses, assets and actual
version before reuse; research access is distinct from clean-room implementation.

## Prove a benefit rather than changing the denominator

Use [adaptive verification](adaptive-verification.md) and its paired trial helper.
Hold the reference, accepted properties, environments, inputs, budgets and
independently prepared holdout fixed. Record first complete accepted journey,
held-out mismatches, protected regressions, false claims and blocked obligations.
Include discovery, fixture/oracle setup, reset, model authoring, execution,
handoffs, tokens/spend, integration, triage, repair and reruns. For runtime changes,
measure input-to-correct-presentation latency, cold/warm/edit/eviction regimes,
validation/synchronization cost and whole-process/device memory. Keep all samples,
failures, missing costs and regimes where the remedy loses.

Passing helper tests only qualifies routing mechanics. A real paired experiment
must support any claim of faster, cheaper or more faithful reconstruction.
