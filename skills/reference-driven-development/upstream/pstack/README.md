# Pinned pstack procedure source

This closure retains original `cursor/plugins` pstack 0.15.15 at commit
`ccb5507cec1546dc88135c1139c811e6c59115ba`, licensed MIT by Lauren Tan.
The [original license](sources/pstack/LICENSE) applies to its 132 source files.
The [manifest](manifest.json) maps original paths to exact retained bytes with
Git blob SHA-1, SHA-256 and byte counts.

Every upstream Markdown file has `.source` appended to its filename. Its bytes
are unchanged. This prevents native discovery of dozens of nested skills and
keeps source instructions inert until deliberately selected. Original relative
links still name original paths. Resolve them through
`scripts/factory_procedures.py resolve <original-path> <relative-reference>`;
do not silently rewrite source text or treat a missing dependency as available.

The closure retains producing, grounding/design, principles, verification,
debugging and recovery families with their supporting files. Only the task's
selected paths and applicable conditional modules enter its native context.
Retaining a file does not install its dependencies, execute its helpers, select
its models, authorize its external actions, or establish procedural application.

The [native procedure wrapper](../../references/factory-procedures.md) defines
selection, source reads, actual producing assignments and intentional host
adaptations. The selector rejects changed, missing or extra source files and
active nested `SKILL.md` files. Hashes establish integrity against this manifest;
they are not signatures or evidence of speed, fidelity or live application.

No scheduler, automation, provider, global rules or service is installed here.
Upstream orchestration/PR helpers remain retained only until separately selected,
authorized and qualified. The original orchestration and shipping procedures
have different Graphite assumptions. The original bootstrap can install Bun
dependencies. Neither is a read-only invocation.
